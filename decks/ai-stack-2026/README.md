# AI 时代，什么被折叠，什么不能

**计算机基础栈 vs 个人的本质栈** · 27 页 · 图文版（1600×900 每页整图）

整理自一场 60 分钟的分享《AI 时代计算机技术知识基础栈》。上半场讲计算机技术的基础栈（机房与硬件 → 内核与网络 → 运行时与容器 → 数据与协议 → 模型运行时，五层）；下半场讲个人的本质栈（金字塔原理、MECE、STAR、BSC 四个思维模型）。核心论点：AI 折叠了「怎么做」，没有折叠「做到什么程度算对」；公共栈决定你能走多稳，私有栈决定你能走多远。
