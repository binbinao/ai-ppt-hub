# 从下山到矩阵几何：梯度下降优化器的七十年

**SGD → 动量 → Adam → AdamW → Muon**

一份 37 页的教学 PPT，讲清楚三件事：

1. 梯度下降七十年，四次范式转移分别在解决什么问题；
2. Adam 为什么有效、又为什么会被 weight decay 和收敛性反例卡住；
3. AdamW 做对了什么，Muon 又为什么把更新当成矩阵来整形。

> 适合有一定深度学习基础、想搞清优化器选型的人；按 60–90 分钟技术分享设计，每页都带演讲者备注。

---

## 三个核心结论

- **Adam 的鲁棒，主要来自逐坐标归一化**：它把“每个方向走多远”从全局学习率里拆出来，代价是看不见参数之间的尺度关系。
- **AdamW 的关键不是新公式，而是解耦**：L2 正则和 weight decay 对 SGD 等价、对 Adam 不等价；把正则从自适应分母里拿出来，才有论文里 15% 的相对测试误差改进。
- **Muon 换了一个对象**：不再逐元素调步长，而是把 2D 权重矩阵的更新做正交化（牛顿–舒尔茨迭代），利用“矩阵更新几乎低秩”这一结构。它在预训练上省算力，但不是万能优化器：embedding、输出层、标量仍要 AdamW。

## 复现实验

Toy 实验只依赖 `numpy` 与 `matplotlib`（不需要 GPU、不需要 PyTorch）：

```bash
cd gd-optimizers-2026
python3 experiment.py
```

会重新生成 `figs/` 下的图与 `experiment-results.json`。实验对象是二维病态二次函数

```
f(θ) = ½ (θ₁² + 100 θ₂²)
```

初始点 `(−2.6, 2.2)`，目标是把损失降到初始值的 `1e-6`。三种优化器各自做 40 点学习率网格搜索，记录达到目标所需步数；另做固定 200 步的学习率稳定性扫描。Muon 部分用一个 64×32 的合成矩阵，比较牛顿–舒尔茨迭代前后的奇异值谱。

结果（详见 `experiment-results.json`）：

| 优化器 | 达到目标步数 | 该次学习率 |
|---|---|---|
| SGD | 263 | 0.018 |
| 动量 (β=0.9) | 90 | 0.00344 |
| Adam | 83 | 0.5789 |

固定 200 步时仍能稳定的学习率区间：SGD `0.001–0.019`，动量到 `0.037`，Adam `0.001–3.0`。Muon 的 64×32 矩阵在 5 步 NS 迭代后，最小奇异值从 `0.02` 升到 `0.682`，最大 `1.132`。

> 这些是**教学用 Toy 数字**，只说明定性差异，不能外推成“Adam 比 SGD 快 3 倍”这类结论。

## 引用与边界

- 所有关键数字都在页脚标注了一手来源；完整清单见第 36 页与 `research-notes.md`。
- 15% 指**相对测试误差改进**，不是绝对准确率提升 15 个百分点。
- Muon 的结论主要来自**预训练**（CIFAR-10、NanoGPT、Moonlight、Kimi K2）；作者明确表示尚未证明 fine-tune / RL 同样有效。
- Llama 3 论文正文没有给出 AdamW 的 β₁/β₂，第 21 页据此标注“正文未给出”，没有替它编数。
- 历史细节（如 Transformer 原论文的 Adam 超参）属于领域常识，正文未逐字核验，引用时请以原论文为准。
